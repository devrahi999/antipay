# **App Name**: AntiPay

## Core Features:

- User Authentication: Enable user signup and login to provide secure access to the application dashboard.
- API Key & Store Configuration: Allow users to create and manage API keys that embed full store identity details (name, URL, logo, support email, success redirect URL), stored in Firestore.
- Payment Method Setup: Provide a user interface to enable or disable various payment methods (e.g., bKash, Nagad, Rocket) and configure associated receiver numbers, stored in Firestore.
- Dashboard Overview: Display a centralized dashboard for users to view their configured store information, enabled payment methods, and an overview of their account status.
- Transaction Monitoring: Show a comprehensive list of all transactions linked to the user's API keys, enabling easy monitoring of payment activities.
- Subscription Management: Enable users to view and manage their subscription plans and access levels.

## Style Guidelines:

- Primary color: A modern, vibrant green (#16A34A) representing growth and trustworthiness, suitable for actions and highlights in a business context. This color is derived from a concept of contemporary SaaS aesthetic and brand reliability.
- Background color: A subtle, very light greenish-gray (#ECF7F0) to ensure a clean and spacious feel, visually harmonizing with the primary color while maintaining high readability on a light scheme.
- Accent color: A lively chartreuse green (#B4E678) as an analogous accent, providing visual pop for calls-to-action and important interactive elements, creating good contrast with the primary color and background.
- Headline and body font: 'Inter', a neutral and highly readable sans-serif typeface, to ensure clarity and a modern, professional appearance across all textual content.
- Employ functional, minimalist line icons to complement the clean and modern SaaS aesthetic, ensuring quick comprehension of features and actions.
- Adopt a clean, minimal, and card-based layout approach to present information clearly and hierarchically, enhancing user navigation and readability across dashboards and forms.
